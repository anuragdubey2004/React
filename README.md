# React Learning Journey

This repository is a complete record of my step-by-step journey learning React. I have organized the code into separate, numbered folders so it is easy to find and review specific topics. 

## Topics Covered

This project covers everything from the basics to advanced data management. Based on the folder list, here is what you will find inside:

* **Basics:** Folder structure, Components, and Props.
* **Styling:** Adding CSS and setting up Tailwind.
* **State & Data:** Using `useState`, handling forms, two-way data binding, and saving data to Local Storage.
* **Hooks & APIs:** Using `useEffect`, custom functions, and calling external APIs.
* **Navigation:** Basic and Advanced Routing to move between different web pages.
* **Global State:** Using the Context API and Redux to manage data across the entire application.

## How to Use This Repository

Each folder acts as a small, separate lesson. If you want to test the code for a specific topic on your computer:

1. Open your terminal.
2. Move into the folder you want to view (for example: `cd 06-useState`).
3. Install the needed tools by running: `npm install`
4. Start the local server by running: `npm start` (or `npm run dev` if it uses Vite).
